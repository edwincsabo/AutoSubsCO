# Contribuir

Revisa [LICENSE](LICENSE), [NOTICE](NOTICE) y [USO_NO_COMERCIAL.md](USO_NO_COMERCIAL.md). Las contribuciones destinadas a incorporarse a AutoSubsCO deben ofrecerse bajo los mismos términos para el código del proyecto. No incorpores código o recursos cuyos términos no permitan su uso en esta distribución.

1. Ejecuta `npm test` y las verificaciones de medios/interfaz apropiadas.
2. Conserva CPU funcional y GPU opcional.
3. Mantén proyectos, medios originales y edición deshacible.
4. Describe el comportamiento, las pruebas ejecutadas y sus límites.
5. Excluye datos de usuarios, modelos, medios privados, perfiles, claves y certificados.

La interfaz mantiene Medios / Montaje / Audio / Subtítulos / Entrega. Agrupa las herramientas por tarea y utiliza el inspector contextual.
